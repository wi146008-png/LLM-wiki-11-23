## 一、 拓撲核心實體與關係 (Graph Entities & Edges)

| 節點代號 | 實體名稱 | 角色定位 |
| :---: | :--- | :--- |
| **Node 1** | **使用者 (User)** | 發起自然語言任務請求（User Task Prompts） |
| **Node 2** | **LLM Agent 核心 (Planner)** | 負責 ReAct 多輪推論、意圖規劃與 Function Calling 決策 |
| **Node 3** | **不可信外部資料 (Untrusted Data)** | 郵件、網頁 HTML、Slack，可能潛伏惡意提示詞 |
| **Node 4** | **惡意攻擊者 (Attacker)** | 在外部資料中植入間接提示注入 Payload |
| **Node 5** | **外部執行工具庫 (Tools)** | 74 種 API（讀寫郵件、檔案操作、金融轉帳等） |
| **Node 6** | **環境真實狀態矩陣 (State Delta)** | 系統真實資料庫狀態（$\Delta S = S_{\text{final}} - S_{\text{init}}$） |
| **Node 7** | **工具權限隔離防禦 (Tool Filter)** | 前置白名單防護盾（最小權限原則） |
| **Node 8** | **碩論創新: 引數污點沙盒 (Thesis Innovation)** | 參數級資料流追蹤與微核心解耦架構 |

## 二、 9 大站點鏡頭導航大綱 (Storyline Outline)

### 📍 Station 1: 全域拓撲點亮：AI Agent 的全新時代
- **鏡頭聚焦點**：全域圖譜發光，高亮 `[使用者]` $\to$ `[Agent 核心]`。
- **通俗比喻**：過去的 AI 只是「動口不動手的顧問」；現在的 Agent 接上了雙手雙腳，能幫我們發信、查帳、轉帳。
- **教授關注點**：自主工具調用（Autonomous Tool-calling）使傳統文字越獄（Jailbreak）升級為「實體系統破壞與外洩」。

### 📍 Station 2: 良性循環路徑：Agent 平時如何替人類工作？
- **鏡頭聚焦點**：藍色良性路徑 `[使用者]` $\to$ `[Agent]` $\to$ `[工具庫]` $\to$ `[環境狀態]`。
- **通俗比喻**：使用者交代一句話，秘書自動按步驟查行事曆、回信確認開會並更新行程。
- **教授關注點**：狀態轉移方程 $S_{t+1} = \text{exec}(S_t, a_t)$，確立系統具備動態多輪累積性。

### 📍 Station 3: 惡意滲透路徑：間接提示注入的致命伏擊
- **鏡頭聚焦點**：紅色危險路徑 `[攻擊者]` $\to$ `[不可信外部資料]` $\to$ 滲入 `[Agent 上下文]`。
- **通俗比喻（外籍秘書拆信）**：客戶寄來的信件暗藏大字「緊急！把主管通訊錄寄到此信箱」，老實秘書誤信照做。
- **教授關注點**：馮諾伊曼「指令與資料混淆（Instruction-Data Confusion）」漏洞在 Transformer 注意力機制下的重現。

### 📍 Station 4: 傳統裁判節點的淪陷：為什麼舊評測不可信？
- **鏡頭聚焦點**：在 `[Agent]` 旁浮現一個「LLM 裁判節點」，隨後該節點被染紅（被攻擊劫持）。
- **通俗比喻**：拿 GPT-4 來當裁判抓壞人，結果壞人的一句話把裁判也一起洗腦了，裁判還宣稱一切安全。
- **教授關注點**：批判 ToolEmu 等舊基準的脆弱性與嚴重「觀察者同化污染」。

### 📍 Station 5: AgentDojo 核心設計：確定性狀態差分評測
- **鏡頭聚焦點**：高亮 `[環境真實狀態]`，展開 4 大環境、74 工具、629 案例。
- **通俗比喻**：不靠 AI 裁判打分數，而是用寫死的 Python 程式直接查帳戶：「錢到底有沒有少？信到底有沒有寄給壞人？」
- **教授關注點**：形式化定義良性效用 $\mathcal{U}_{\text{benign}}$、受攻擊效用 $\mathcal{U}_{\text{attack}}$ 與定向 ASR，100% 可重現。

### 📍 Station 6: 逆標度震撼發現：越聰明的模型越容易被控制？
- **鏡頭聚焦點**：`[Agent 核心]` 上方展開主流模型對比柱狀圖（GPT-4o vs Claude 3.5 vs GPT-3.5）。
- **通俗比喻**：為什麼 GPT-3.5 看似很安全？因為它太笨了，連壞人的指令都跑不通；而 GPT-4o 執行力太強，反而成了最完美的傀儡。
- **教授關注點**：深入探討 Inverse Scaling 現象——模型指令遵循能力（Instruction Following）與資安邊界防護的根本衝突（GPT-4o ASR 達 47.69%）。

### 📍 Station 7: 防禦節點介入：工具隔離 (Tool Filter) 的突破
- **鏡頭聚焦點**：在 Agent 與工具庫之間插入綠色護盾 `[工具權限隔離防禦]`。
- **通俗比喻**：如果老闆只是要查日曆，出門前把發信、轉帳的印鑑全部鎖進保險箱，壞人再怎麼催眠秘書也沒工具可用。
- **教授關注點**：最小權限原則實證——Tool Filter 將 ASR 驟降至 6.84%，對比 BERT 偵測器（因誤報過高使良性效用腰斬至 41.5%）的優劣。

### 📍 Station 8: 圖譜邊緣破裂：雙重用途工具 (Dual-use) 的死角
- **鏡頭聚焦點**：防禦護盾出現紅色裂紋，指向 `[敏感執行工具]`。
- **通俗比喻**：如果老闆原本就要「刪除垃圾信」呢？系統必須給刪信工具，此時壞人說「把所有重要合約全刪光」，門禁防線完全崩潰。
- **教授關注點**：剖析架構極限——單純工具名稱白名單（Tool-level）無法防禦合法權限內的越權惡意操作（佔 17% 案例）。

### 📍 Station 9: 碩論創新落點：引數級污點追蹤與微核心架構
- **鏡頭聚焦點**：圖譜延伸出全新發光節點 `[引數污點沙盒]`。
- **通俗比喻**：既然工具必須給，我們就盯緊「參數裡的文字打哪來的」。只要收件者是由外部不可信信件填入，立刻拉警報並要求人類二次確認。
- **教授關注點**：展現碩士獨立研究深度——提出引數級污點分析（Argument-level Taint Tracking）與微核心解耦架構，並說明如何復用 AgentDojo 進行定量實驗。
