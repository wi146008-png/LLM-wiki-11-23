🎓 預期教授提問與答辯錦囊 (Professor Q&A Defense Strategy) DEFENSE KIT
Q1：既然 Tool Filter 那麼有效（ASR 降到 6.84%），為什麼我們還需要大費周章做引數追蹤？
答辯思路：「報告教授，Tool Filter 雖然有效，但論文承認有 17% 的雙重用途案例它完全失效。在真實工業應用中，使用者最常要求 Agent 做的事恰恰就是『回信』與『修改檔案』，如果這 17% 的寫入情境無法防禦，整個系統在真實環境中依然是形同虛設的，因此引數級防護是補齊這最後一哩路的必要手段。」
Q2：污點分析在 LLM 這種純文字黑盒子中該如何實作？會不會開銷過大？
答辯思路：「報告教授，這正是我們碩論創新的核心難點。我們不需要在神經網路內部追蹤權重，而是在 Function Calling 的中介軟體（Middleware）層建立抽象語法樹與資料流圖，透過比對字串來源與外部 API 輸出的相似度，以輕量級沙盒進行攔截，將延遲控制在毫秒級。」
Q3：Claude 3.5 Sonnet 表現比 GPT-4o 好，這代表什麼？
答辯思路：「報告教授，這反映出模型在後訓練（Post-training）階段對 System Prompt 優先級的對齊差異。Anthropic 在模型訓練時更加強調上下文邊界（Context Boundaries），這啟發了我們：架構防禦與訓練對齊雙管齊下，是提升 Agent 魯棒性的最佳途徑。」
